Crear una nueva rama de pruebas en GIT
Cree una rama nueva llamada experimentación
En esa rama:
Cree una carpeta Ejercicios_Extra_Git
Agregue un archivo prueba.txt con un mensaje de prueba
Haga commit y súbalo a GitHub
No lo mezcle (merge) con la rama principal todavía
